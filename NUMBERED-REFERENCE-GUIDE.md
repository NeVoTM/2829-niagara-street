## **🎯 QUICK USAGE PATTERNS**

### **Starting a Session:**
```
1. Run: WarpSpeed
2. Run: ComplianceCheck (Ctrl+Shift+C)
3. Choose project type: NEW/EXISTING/ISSUES
```

### **During Development:**
```
• Mobile issues → DebugRef (Ctrl+Shift+D)
• File updates → GitHubFirst (Ctrl+Shift+G) + UpdateFlow (Ctrl+Shift+U)
• AI not following system → NumRef (Ctrl+Shift+N)
```

### **Before Deployment:**
```
1. Run: DataCheck (Ctrl+Shift+V)
2. Run: QACheck (Ctrl+Shift+Q)
3. Test mobile viewport
4. Deploy to GitHub
```

### **Common AI Redirections:**
```
• "Apply DEBUGGING-CHECKLIST.md SECTION 4.3" (alignment)
• "Follow Universal Access Principle per SECTION 4.0" (GitHub first)
• "Use numbered references per SECTION 7.1" (proper format)
• "Check existing solution in ISSUE 4.X" (avoid re-debugging)
```
