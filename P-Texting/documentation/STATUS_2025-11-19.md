## 💡 TROUBLESHOOTING AFTER RESTART

### If Still Getting "Cannot connect to Chrome DevTools":

1. **Verify Chrome started correctly**:
   ```powershell
   netstat -ano | findstr ":9222"
   ```
   Should show LISTENING. If not, Chrome didn't start in debug mode.

2. **Check Windows Firewall**:
   - Port 9222 might be blocked
   - Try temporarily disabling firewall for testing

3. **Check Antivirus**:
   - Might be blocking Chrome remote debugging
   - Add exception for Chrome.exe and port 9222

4. **Try Running as Administrator**:
   - Right-click Chrome shortcut
   - "Run as administrator"
   - Type the command with --remote-debugging-port=9222

5. **Check Other Chrome Instances**:
   ```powershell
   Get-Process chrome | Measure-Object
   ```
   If multiple, close ALL and start fresh

1. **Check screenshot**: `logs/screenshots/failed_*.png`
