## **⚡ RECOMMENDED WARP CUSTOM COMMANDS**

### **Setup Instructions:**
Navigate to: `Settings > Features > Custom Commands > Add Command`

### **🎯 Priority Commands (Set up first):**

**Command 1: Quick Debug Reference**
```

Command: "echo 'DEBUGGING-CHECKLIST.md Quick Reference:'; echo 'ISSUE 4.1: Infinite scroll (max-height: 100vh)'; echo 'ISSUE 4.2: Chart sizing (max-height: 280px)'; echo 'ISSUE 4.3: Alignment (separate tables)'; echo 'ISSUE 4.4: Text visibility (text-shadow)'; echo 'ISSUE 4.7: Mobile usability (44px targets)'"
```

**Command 2: Universal Access Reminder**

## **🎯 USAGE PATTERNS**

### **When to Use Each Command:**

**During AI Sessions:**
- Start with `ComplianceCheck` to ensure proper workflow
- Use `NumRef` when Warp AI isn't using numbered references  
- Use `GitHubFirst` when Warp tries to update local files first
- Use `DebugRef` for common mobile/alignment issues

**During Development:**
- Use `MobileFirst` before starting interface work
- Use `DataCheck` after editing project-data.json
- Use `QACheck` before deployment
- Use `UpdateFlow` when updating universal files

### **AI Redirection Commands:**
When Warp AI forgets procedures, type these shortcuts instead of explaining again:

- **Warp violates numbering system** → `NumRef`
- **Warp updates local files first** → `GitHubFirst`  
- **Warp suggests generic solutions** → `DebugRef`
- **Warp skips cross-references** → `UpdateFlow`
