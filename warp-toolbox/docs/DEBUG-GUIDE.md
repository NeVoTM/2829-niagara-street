## **SECTION 2: LAYOUT DEBUGGING (Your Request)**

### **2.1 Layout Border Overlap Error**
**Section:** 2 (Errors Tab)  
**Sub-section:** 2.1 (Layout Issues)
**Location:** Green tab → Layout Issues category

**How to access:**
1. Type `v` to open visual interface
2. Press **Ctrl+2** or click **🚨 ERRORS** tab (Green)
3. Click **🎨 Layout Issues** box
4. Or search: "Layout border overlap"

**Command line shortcut:**
```powershell
e "Layout border overlap"
```

**Solution provided:**
- **Problem:** CSS borders or margins overlapping text content
- **Fix:** Check border-box sizing, margins, and padding
- **Commands:** Inspect element → Check CSS: margin, padding, border-box
- **Quick CSS fix:** `* { box-sizing: border-box; }`

### **2.2 Text Alignment Error**
**Section:** 2 (Errors Tab)
**Sub-section:** 2.2 (Text Layout)  
**Location:** Green tab → Text Layout category

**How to access:**
1. Type `v` → **Ctrl+2** → **📝 Text Layout**
2. Or command: `e "Text alignment error"`

**Solution provided:**
- **Problem:** Text positioning and alignment issues
- **Fix:** Check CSS text-align, display, flex properties
- **Quick CSS fix:** `text-align: left; display: block;`
