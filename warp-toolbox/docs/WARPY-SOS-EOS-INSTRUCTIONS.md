## ⚠️ VIOLATION PREVENTION DURING SESSIONS

### **SYSTEMATIC APPROACH REQUIREMENTS:**
1. **When updating ONE command box → Update ALL similar command boxes**
2. **When adding numbered sections → Follow sequential numbering**
3. **When modifying files → Update ALL cross-references**
4. **When implementing features → Apply consistently across interface**

### **COMMON VIOLATIONS TO PREVENT:**
- ❌ Partial implementations (fixing one tab but not others)
- ❌ Ignoring numbered reference requests ("what section?")
- ❌ Working only with local files (not GitHub master)
- ❌ Breaking numbering sequence (using X.X instead of numbers)
- ❌ Updating files in isolation (not cross-references)

### **IMMEDIATE RECOVERY WHEN VIOLATION OCCURS:**
1. **ACKNOWLEDGE:** "I should have applied this systematically"
2. **CORRECT:** Go to proper GitHub files and numbered sections
3. **APPLY:** Use exact solutions with proper formatting
4. **UPDATE:** Fix all cross-references that were missed
5. **VERIFY:** Ensure systematic completion across all instances
