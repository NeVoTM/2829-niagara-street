## 📊 FILE CATEGORIES:

### 🚀 CORE EXECUTION (core/)
- QuickStart.ps1, DebugToolbox.ps1, LayoutDebugger.ps1
- **Purpose:** Direct command execution and system functionality

### 📚 DOCUMENTATION (docs/)  
- User guides, cheat sheets, methodology documents
- **Purpose:** Human-readable instructions and references

### 📝 TEMPLATES (templates/)
- Reusable templates for AI training and session management
- **Purpose:** Standardized formats for consistency

### ⚙️ PROCEDURES (procedures/)
- Step-by-step processes and checklists
- **Purpose:** Systematic workflow management

### 📋 REFERENCE (reference/)
- Master files with numbered sections and compliance rules
- **Purpose:** Authoritative source for procedures and tracking

### 💾 BACKUPS (moved-deleted-copied-30day-storage/)
- 30-day retention system for deprecated files
- **Purpose:** Safety net and recovery system

## 🔄 MAINTENANCE:

### CLEANUP SCHEDULE:
- **Daily:** Check core/ for new temporary files
- **Weekly:** Verify backup retention in moved-deleted-copied-30day-storage/
- **Monthly:** Archive old notifications/ files
- **Quarterly:** Review and update reference/ master files

### SYNC REQUIREMENTS:
- All core/ files must be synced across machines
- reference/ files are GitHub master source
- moved-deleted-copied-30day-storage/ is machine-local only
